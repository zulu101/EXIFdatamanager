# Screenshots

Place screenshots for the README here and uncomment the image block in `README.md` and
`README.de.md`. Expected file names:

| File | Content |
| --- | --- |
| `main-window.png` | Main window with photo list, preview and editor |
| `faces.png` | Marked faces with names |
| `batch-editing.png` | Batch editing of several photos |

Tip: take screenshots of a window with ⇧⌘4, then Space, then click the window (hold ⌥ to omit the shadow).
